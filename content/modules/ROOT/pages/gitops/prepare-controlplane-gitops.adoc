= Creating the RHOSO Controlplane Overlay Configuration

== Creating the initial overlay

Change directory to your forked gitops repo, in your bastion:

[source,bash,role=execute]
----
cd /home/lab-user/rhoso-gitops/gitops
----

The `base/controlplane` directory already consumes the upstream RHOSO controlplane catalog component (`openstack-k8s-operators/gitops`). In this chapter you create an environment overlay that patches that catalog default into the lab control plane.

Create the environment directory to store the managed cluster overlay configuration:

[source,bash,role=execute]
----
mkdir -p environments/demo-env/controlplane
----

[source,bash,role=execute]
----
cat > environments/demo-env/controlplane/kustomization.yaml <<'EOF'
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
transformers:
  - |-
    apiVersion: builtin
    kind: NamespaceTransformer
    metadata:
      name: notImportantHere
      namespace: cifmw-demo
    unsetOnly: true
resources:
  - controlplane-patches
EOF
----

== Creating the Controlplane Environment Overlay

Create the controlplane patches directory to store the overlay patches:

[source,bash,role=execute]

mkdir -p environments/demo-env/controlplane/controlplane-patches

=== Configuring RHOSO Controlplane patches

==== Creating the patches configuration

Create the *kustomization.yaml* for the demo-env environment overlay configuration.
It starts from `base/controlplane` (the catalog controlplane component). Patches are added after you create the thematic files below:

[source,bash,role=execute]
----
cat > environments/demo-env/controlplane/controlplane-patches/kustomization.yaml <<'EOF'
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
transformers:
  - |-
    apiVersion: builtin
    kind: NamespaceTransformer
    metadata:
      name: notImportantHere
      namespace: openstack
    unsetOnly: true
resources:
  - ../../../../base/controlplane
EOF
----

Validate the catalog base configuration can be generated with *kustomize build*:

[source,bash,role=execute]
----
kustomize build environments/demo-env/controlplane/controlplane-patches
----

==== Applying thematic control plane patches

The catalog `OpenStackControlPlane` is a production-oriented default.
The following patches adapt it for this lab: storage class, DNS and MetalLB addresses, replica scale, Cinder NFS, Nova/OVN networking, and which optional services are enabled.
Each patch uses `$patch: replace` on the service sections it owns so catalog fields that do not apply to the lab are removed cleanly.

[IMPORTANT]
The commands below use a **quoted** heredoc (`<<'EOF'`).
That keeps `$patch` literal in the YAML.
If you use unquoted `<<EOF`, the shell expands `$patch` to empty and kustomize fails with `unable to parse SM or JSON patch`.

===== Configuring storage

Set the lab ODF storage class, shrink Galera PVC requests, and configure Glance storage.

[source,bash,role=execute]
----
cat > environments/demo-env/controlplane/controlplane-patches/patch-storage.yaml <<'EOF'
# Lab storage settings: ODF storage class and smaller Galera PVCs.
apiVersion: core.openstack.org/v1beta1
kind: OpenStackControlPlane
metadata:
  name: openstack-control-plane
spec:
  storageClass: ocs-external-storagecluster-ceph-rbd
  galera:
    $patch: replace
    templates:
      openstack:
        storageRequest: 500M
      openstack-cell1:
        storageRequest: 500M
  glance:
    $patch: replace
    enabled: true
    template:
      databaseInstance: openstack
      storage:
        storageRequest: 10G
        storageClass: "ocs-external-storagecluster-ceph-rbd"
      keystoneEndpoint: default
      glanceAPIs:
        default:
          type: single
          replicas: 1
          override:
            service:
              internal:
                metadata:
                  annotations:
                    metallb.universe.tf/address-pool: internalapi
                    metallb.universe.tf/allow-shared-ip: internalapi
                    metallb.universe.tf/loadBalancerIPs: 172.17.0.89
                spec:
                  type: LoadBalancer
          networkAttachments:
            - storage
EOF
----

===== Configuring DNS

Point the DNS service MetalLB VIP at the lab ctlplane address and use the cluster DNS resolver.

[source,bash,role=execute]
----
cat > environments/demo-env/controlplane/controlplane-patches/patch-dns.yaml <<'EOF'
# DNS for the lab: ctlplane MetalLB VIP and cluster DNS resolver.
apiVersion: core.openstack.org/v1beta1
kind: OpenStackControlPlane
metadata:
  name: openstack-control-plane
spec:
  dns:
    $patch: replace
    template:
      override:
        service:
          metadata:
            annotations:
              metallb.universe.tf/address-pool: ctlplane
              metallb.universe.tf/allow-shared-ip: ctlplane
              metallb.universe.tf/loadBalancerIPs: 172.22.0.89
          spec:
            type: LoadBalancer
      options:
      - key: server
        values:
        - 172.30.0.10
      replicas: 1
EOF
----

===== Scaling down for the lab

Reduce Memcached and RabbitMQ from the catalog HA defaults to a lab-sized footprint.

[source,bash,role=execute]
----
cat > environments/demo-env/controlplane/controlplane-patches/patch-scale.yaml <<'EOF'
# Scale down HA replicas for the single-node lab footprint.
apiVersion: core.openstack.org/v1beta1

  name: openstack-control-plane

    $patch: replace

      memcached:
        replicas: 1

===== Configuring the Cinder NFS backend

Replace the catalog `volume1` placeholder with the lab NFS volume backend.

[source,bash,role=execute]
----
cat > environments/demo-env/controlplane/controlplane-patches/patch-cinder-nfs.yaml <<'EOF'
# Cinder NFS backend for the lab (replace catalog volume1 placeholder).
apiVersion: core.openstack.org/v1beta1
kind: OpenStackControlPlane
metadata:
  name: openstack-control-plane
spec:
  cinder:
    $patch: replace
    enabled: true
    apiOverride:
      route: {}
    template:
      databaseInstance: openstack
      secret: osp-secret
      cinderAPI:
        override:
          service:
            internal:
              metadata:
                annotations:
                  metallb.universe.tf/address-pool: internalapi
                  metallb.universe.tf/allow-shared-ip: internalapi
                  metallb.universe.tf/loadBalancerIPs: 172.17.0.89
              spec:
                type: LoadBalancer
      cinderScheduler:
        replicas: 1
      cinderBackup:
        networkAttachments:
        - storage
        replicas: 0 # backend needs to be configured
      cinderVolumes:
        nfs:
          networkAttachments:
          - storage
          customServiceConfig: |
            [nfs]
            volume_backend_name=nfs
            volume_driver=cinder.volume.drivers.nfs.NfsDriver
            nfs_snapshot_support=true
            nas_secure_file_operations=false
            nas_secure_file_permissions=false
          customServiceConfigSecrets:
          - cinder-nfs-config
EOF
----

==== Wire the patches into kustomization.yaml

Update `controlplane-patches/kustomization.yaml` so it applies every thematic patch:

[source,bash,role=execute]
----
cat > environments/demo-env/controlplane/controlplane-patches/kustomization.yaml <<'EOF'
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
transformers:
  - |-
    apiVersion: builtin
    kind: NamespaceTransformer
    metadata:
      name: notImportantHere
      namespace: openstack
    unsetOnly: true
resources:
  - ../../../../base/controlplane
patches:
  - path: patch-storage.yaml
    target:
      kind: OpenStackControlPlane
      name: openstack-control-plane
  - path: patch-dns.yaml
    target:
      kind: OpenStackControlPlane
      name: openstack-control-plane
  - path: patch-metallb-ips.yaml
    target:
      kind: OpenStackControlPlane
      name: openstack-control-plane
  - path: patch-scale.yaml
    target:
      kind: OpenStackControlPlane
      name: openstack-control-plane
  - path: patch-cinder-nfs.yaml
    target:
      kind: OpenStackControlPlane
      name: openstack-control-plane
  - path: patch-nova-ovn.yaml
    target:
      kind: OpenStackControlPlane
      name: openstack-control-plane
  - path: patch-services.yaml
    target:
      kind: OpenStackControlPlane
      name: openstack-control-plane
EOF
----

Validate the patched overlay:

[source,bash,role=execute]
----
kustomize build environments/demo-env/controlplane/controlplane-patches
----

Validate the full environment overlay:

[source,bash,role=execute]
----
kustomize build environments/demo-env/controlplane
----

Commit the files created and push them to your GitHub repo:
